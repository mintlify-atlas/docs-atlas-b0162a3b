The Python client provides a Pythonic interface for communicating with the Membrane daemon over gRPC using the protobuf-defined service contract.

## Installation

Install from the project root:

```bash
pip install -e clients/python
```

Or with development dependencies:

```bash
pip install -e clients/python[dev]
```

**Requirements:**
- Python >= 3.10
- `grpcio >= 1.78.0`
- `protobuf >= 6.31.1`
- A running Membrane daemon (default: `localhost:9090`)

## Quick Start

```python
from membrane import MembraneClient, Sensitivity, TrustContext

# Connect to the running Membrane daemon
client = MembraneClient("localhost:9090")

# Ingest an event
record = client.ingest_event(
    event_kind="file_edit",
    ref="src/main.py",
    summary="Refactored authentication module",
    sensitivity=Sensitivity.LOW,
)
print(f"Created record: {record.id}")

# Retrieve memories relevant to a task
trust = TrustContext(
    max_sensitivity=Sensitivity.MEDIUM,
    authenticated=True,
    actor_id="agent-1",
)
records = client.retrieve("fix the login bug", trust=trust, limit=5)
for r in records:
    print(f"  [{r.type.value}] {r.id} (salience={r.salience:.2f})")

# Reinforce a useful memory
client.reinforce(record.id, actor="agent-1", rationale="Used successfully")

# Clean up
client.close()
```

### Context Manager

The client supports context manager protocol for automatic cleanup:

```python
with MembraneClient("localhost:9090") as client:
    record = client.ingest_observation(
        subject="user",
        predicate="prefers",
        obj={"language": "Python"},
        sensitivity=Sensitivity.LOW,
    )
```

### Retrieval Methods

<Tabs>
  <Tab title="retrieve">
    ```python
    client.retrieve(
        task_descriptor: str,
        trust: TrustContext | None = None,
        limit: int = 10,
        memory_types: list[str] | None = None,
        min_salience: float = 0.0,
    ) -> list[MemoryRecord]
    ```
    
    Retrieve memories relevant to a task. Returns only records (backward-compatible).
    
    **Parameters:**
    - `task_descriptor`: Natural language description of the task
    - `trust`: Trust context for access control
    - `limit`: Maximum number of records to return
    - `memory_types`: Filter by memory types (`["episodic", "semantic", ...]`)
    - `min_salience`: Minimum salience threshold (0.0-1.0)
    
    **Returns:** List of `MemoryRecord` objects
  </Tab>
  
  <Tab title="retrieve_with_selection">
    ```python
    client.retrieve_with_selection(
        task_descriptor: str,
        trust: TrustContext | None = None,
        limit: int = 10,
        memory_types: list[str] | None = None,
        min_salience: float = 0.0,
    ) -> tuple[list[MemoryRecord], SelectionResult | None]
    ```
    
    Retrieve memories plus optional selector metadata.
    
    **Returns:** Tuple of `(records, selection)` where `selection` contains:
    - `selected`: Records selected by the selector
    - `confidence`: Selector confidence score
    - `needs_more`: Whether more context is needed
  </Tab>

    - `trust`: Trust context for access control

## Error Handling

The client raises standard Python exceptions for gRPC errors:

```python
import grpc
from membrane import MembraneClient, Sensitivity, TrustContext

client = MembraneClient("localhost:9090")

try:
    records = client.retrieve(
        "sensitive query",
        trust=TrustContext(max_sensitivity=Sensitivity.LOW, authenticated=False)
    )
except grpc.RpcError as e:
    if e.code() == grpc.StatusCode.PERMISSION_DENIED:
        print(f"Access denied: {e.details()}")
    elif e.code() == grpc.StatusCode.UNAVAILABLE:
        print("Membrane daemon is not running")
    else:
        print(f"RPC failed: {e.code()} - {e.details()}")
```

**Common error codes:**
- `UNAVAILABLE`: Daemon not running or unreachable
- `UNAUTHENTICATED`: Invalid or missing API key
- `PERMISSION_DENIED`: Insufficient trust context for requested sensitivity
- `NOT_FOUND`: Record ID does not exist
- `INVALID_ARGUMENT`: Malformed request parameters

## LLM Integration Pattern

Common workflow: ingest execution traces, retrieve relevant memories, pass context to your model.

```python
import os
from openai import OpenAI
from membrane import MembraneClient, Sensitivity, TrustContext

# Initialize clients
memory = MembraneClient("localhost:9090", api_key=os.getenv("MEMBRANE_API_KEY"))
llm = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# Retrieve relevant memories
trust = TrustContext(
    max_sensitivity=Sensitivity.MEDIUM,
    authenticated=True,
    actor_id="incident-agent",
    scopes=["prod"],
)

records = memory.retrieve(
    "how should I handle this incident?",
    trust=trust,
    memory_types=["semantic", "competence", "working"],
    limit=10,
)

# Format memories for LLM context
memory_context = "\n".join([f"[{r.type.value}] {r.id}: {r.payload}" for r in records])

# Pass to LLM
completion = llm.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "system", "content": "Use the memory context as evidence. Cite record IDs."},
        {"role": "user", "content": f"Incident task:\n...\n\nMemory:\n{memory_context}"},
    ],
)

print(completion.choices[0].message.content)
memory.close()
```
